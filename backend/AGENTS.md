# Generosity backend

PHP 8.4 / Laravel 13 API, with MySQL/MariaDB. Use Docker Compose for PHP and Composer; no host PHP installer is required.

- Follow the repository OpenSpec foundation and write technical artifacts in English.
- Run `docker compose exec app composer test` against the isolated test database.
- Keep credentials and generated dependencies out of Git.
- Use framework authentication, validation, migrations and transactions.
- Do not deploy or change existing hosting sites without a concrete deployment request.
