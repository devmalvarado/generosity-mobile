# OpenSpec Maintenance

## Tooling Baseline

Verified on 2026-10-25: **1.15.0**, the npm `latest` version and the
[official release](https://github.com/Fission-AI/OpenSpec/releases/tag/v1.15.0).
The previous CLI and generated Codex instructions were 1.3.1.
Follow the [official installation documentation](https://openspec.dev/docs/installation)
when updating the tool; `openspec update` refreshes project instructions.

```bash
node --version
npm view @fission-ai/openspec version
npm install -g @fission-ai/openspec@1.15.0
openspec --version
openspec update --dry-run --json
openspec update
```

The npm installation requires Node.js 20.19.0 or newer. Pin the verified
version for reproducible setup; check the registry before a later upgrade.
Do not overwrite a package-manager-owned executable with `npm --force`.

On this Mac, both the nvm Node 22.17.0 prefix and `/opt/homebrew` expose
OpenSpec 1.15.0 installed with npm. Homebrew's catalog download failed and
its cached formula offered only 1.14.3; that upgrade was interrupted before
installation. The old Homebrew 1.3.1 formula is retained but unlinked.
Use `which -a openspec` and `openspec --version` if a different shell selects
another executable. Updating nvm's Node version may require reinstalling its
global tools.

archived artifacts. Never hide incomplete work with unchecked validation
or automatic confirmation flags.
