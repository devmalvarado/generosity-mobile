## Reproduction

From `backend/`, use `docker compose exec -T app composer test` and
`docker compose exec -T app vendor/bin/phpunit --filter FeatureFlagsTest`.
From the repository root, use the build commands in `docs/release-channels.md` and:

```sh
./gradlew :shared:jvmTest :shared:testAndroidHostTest
npm --prefix portal test -- --workers=2
python3 scripts/check-mobile-environment.py --self-test
python3 scripts/prepare-preview-portal.py --self-test
python3 scripts/generate-design-system.py --check
sh scripts/check-localization.sh --self-test
openspec validate add-release-channels-and-feature-controls --strict --no-interactive
```

  `u643005321_gen_preview` database. New centers required `expectedVersion: 0`.
