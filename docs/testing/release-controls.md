Local checks on 2026-11-03, branch `codex/backend-php-mysql`. No hosting deployment,
real user flag changes, physical-device update or provider credential creation.

## Backend

The full PHP 8.4/MariaDB suite passed 99 tests and 5,583 assertions. The additional
feature-control suite (8 tests, 55 assertions, passed) verifies anonymous/account-specific responses, no tester-list
leak, verified administrator allowlist, CSRF, optimistic conflicts, audit entries,
draft/new-publication behavior and acknowledged idempotency replay. A subsequent
case confirms that center confirmation and fulfillment still succeed with all
three flags off, while the received total remains authoritative.

`FeatureFlagsTest` also checks active/verified tester IDs, unsafe preview database,
origins/cookies/mail/push settings and mismatched API/auth channel headers.
`SocialAuthTest` covers preview callback selection, production-client rejection,
mandatory PKCE/state and preview handoff exchange. Existing production OAuth tests
remain passing. Tests use only the isolated `generosity_test` database.

## Reproduction

From `backend/`, use `docker compose exec -T app composer test` and
`docker compose exec -T app vendor/bin/phpunit --filter FeatureFlagsTest`.
From the repository root, use the build commands in `docs/release-channels.md` and:

```sh
./gradlew :shared:jvmTest :shared:testAndroidHostTest
npm --prefix portal test -- --workers=2
python3 scripts/check-mobile-environment.py --self-test
python3 scripts/prepare-preview-portal.py --self-test
python3 scripts/generate-design-system.py --check
sh scripts/check-localization.sh --self-test
openspec validate add-release-channels-and-feature-controls --strict --no-interactive
```

Do not archive the change yet. Preview hosting/database/credentials, approved
administrator assignment, backend-first publication, live flag journeys and
physical-device acceptance are listed separately in its deployment tasks.
